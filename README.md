# Quản lý Tưới – Phun thuốc

Phần mềm quản lý hóa đơn nhập/xuất, tồn kho, doanh thu – lợi nhuận (có biểu đồ). Danh mục vật tư lấy từ file báo giá.

## Chạy app
Giải nén, **bấm đúp `index.html`** (không cần cài đặt, chạy offline).

## Đưa lên GitHub và chạy online
1. Tạo repo, tải toàn bộ file trong thư mục này lên.
2. Settings → Pages → Branch `main` / root → Save.
3. Mở link `https://<tên>.github.io/<repo>/`.

## Lưu ý
- Dữ liệu lưu trong trình duyệt của từng máy. Dùng **Dữ liệu → Sao lưu** để lưu file JSON và **Khôi phục** để chuyển sang máy khác.
- Giá vốn tính theo bình quân gia quyền khi nhập hàng.
- Sửa danh mục gốc: chỉnh `data.js` (tên, giá nhập, giá bán).
